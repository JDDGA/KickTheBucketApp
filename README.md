Kick the Bucket App

Contributors: Alejandro Bautista, Jared Granata

Application Description:

Kick The bucket is a app designed for users to be able to note down their life goals and help track them, as well as serving as
a way to look through all the completed goals, along with the ability to attach photos and create their own profile
to track their statistics. It contains a main menu, a View Goals screen, a Journal screen, a Profile screen and a photo album screen.

Instructions:

Run in intelliJ to open, does not require and prerequisites.
